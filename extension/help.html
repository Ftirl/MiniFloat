MINIFLOAT / 微窗

把视频留在眼角。

一个可以缩得更小、透过画面看到桌面的轻量视频小窗。

首次安装

  1. 在下载目录运行 Install.cmd，注册当前用户的桌面助手，无需管理员权限。
  2. 在 Chrome 地址栏输入 chrome://extensions；Edge 输入 edge://extensions，开启“开发者模式”。
  3. 点击“加载已解压的扩展程序”，选择目录中的 extension 文件夹。
  4. 将“微窗”固定到工具栏。播放网页视频，点击扩展图标，或按 Alt + Shift + V。

小窗操作

  • 拖动画面移动位置；拖动边缘或滚轮调整大小，保持视频比例。
  • Ctrl + 滚轮调整不透明度，范围 10%–100%。
  • 右键打开菜单：尺寸、不透明度、播放/暂停、静音、返回网页。
  • 双击播放/暂停。小窗获得焦点时，空格播放/暂停，左右键快退/快进 5 秒。
  • Ctrl + Alt + O 恢复可见并关闭鼠标穿透；也可使用托盘图标恢复。

使用边界

视频继续由原来的 Chrome 或 Edge 页面播放，不用复制链接，也不必重新登录。原网页需要保持打开；一次显示一个视频。跨域内嵌播放器、受保护视频和禁止画中画的网站可能不支持。本版本不下载视频，不提供独立离线播放。

如果画面黑屏或停止更新，在右键菜单关闭“收起 浏览器原小窗”，检查原画面是否正常。不要手动最小化原小窗。关闭微窗会恢复原窗口位置并退出画中画。

卸载：先关闭小窗，在 Chrome / Edge 中删除扩展，然后运行 Uninstall.cmd。本程序没有开机启动项，也没有网络监听端口。
